## About

**Krishi Mitra** is a digital platform designed to connect farmers directly with consumers, eliminating unnecessary middlemen and helping farmers get better value for their produce.

The platform promotes transparent and direct selling while giving consumers access to fresh, locally sourced agricultural products. It aims to create a simple marketplace where farmers can showcase their products and consumers can discover and purchase them directly.

### Key Features

* 👨‍🌾 Direct connection between farmers and consumers
* 🥕 Marketplace for agricultural products
* 💰 Better value for farmers by reducing middlemen
* 🔍 Easy product discovery for consumers
* 🌱 Access to fresh and locally sourced produce
* 🤝 Transparent and direct transactions

## Running Locally

Clone the repository and navigate to the project directory:

```bash
git clone <repository-url>
cd krishi-mitra
```

Install the required dependencies:

```bash
make install
```

Run the application:

```bash
make run
```
